# Graphite releases

Builds of Graphite and the files the app downloads. The app's source code lives elsewhere.

- `vX.Y.Z` releases: app builds for Mac, Windows, Linux and Android, plus `latest.json` for in-app updates.
- `meaning-dictionary-N` releases: the Czech–English dictionary used by Graphite's meaning engine.

## Dictionary licence

The meaning engine's dictionary is built from Wiktionary (https://en.wiktionary.org) by the Wiktionary
contributors, as extracted by Wiktextract (https://kaikki.org). It is licensed under CC BY-SA 4.0
(https://creativecommons.org/licenses/by-sa/4.0/). It was changed by keeping only Czech words, short English
translations and word forms, in a compact JSON format.
